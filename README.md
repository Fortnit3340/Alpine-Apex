# Alpine Apex

Free browser car game — mountain highway + duels.

## 🎮 Play the Game

**[🎮 PLAY THE GAME NOW 🎮](https://fortnit3340.github.io/Alpine-Apex/index.html)**

Or open `index.html` locally to run the game in your browser!

## About

Enjoy racing and dueling on mountain highways! Alpine Apex is a fun, fast-paced car game built with HTML and JavaScript.

## Features

- Race on challenging mountain highways
- Engage in intense duels with opponents
- Smooth gameplay and responsive controls
- Play directly in your browser (no installation needed)

## How to Run Locally

1. Clone the repository
2. Open `index.html` in your web browser
3. Start racing!

## Files

- **index.html** - Main game file (the complete game)
- **manifest.json** - PWA configuration for installable app
- **sw.js** - Service worker for offline support
- **icon-192.png** & **icon-512.png** - App icons

Enjoy the race! 🏎️
